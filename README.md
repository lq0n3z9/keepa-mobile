# keepa-mobile

KeepaをiPhoneのSafariで使いやすくするユーザースクリプトです。

## できること

- 製品ファインダーの検索結果を、スマホで見やすいカードで表示します
- 条件の入力欄を1列に並べ、数字キーボードで入力できるようにします
- 商品ごとのトラッキング（値下がりのお知らせ）を、スマホで設定しやすくします
- トラッキング中の商品を一覧にして、チェックを付けてまとめて削除できます（削除の前に必ず確認画面が出ます）
- 「あとで見るリスト」（自分のGoogleスプレッドシート）に商品を保存できます（使うかどうかは自由です）

Keepaのアカウント（トラッキングにはログイン）が必要です。このスクリプトはKeepaの公式のものではありません。

## 入れ方（iPhone）

1. App Storeで「Userscripts」（無料）を入れます。
2. 「設定」→「アプリ」→「Safari」→「機能拡張」→「Userscripts」をオンにし、「その他のWebサイト」を「許可」にします。
3. Safariで次のURLを開きます。
   https://raw.githubusercontent.com/lq0n3z9/keepa-mobile/main/keepa-finder-mobile.user.js
4. アドレスバーの「ぁあ」（または拡張機能のアイコン）→「Userscripts」をタップし、出てきた「インストール」の案内をタップします。
5. Safariで https://keepa.com を開きます。画面の下に小さな版番号が出たら準備完了です。

## 新しい版にするには

- Userscriptsが定期的に新しい版を確かめます。Keepaを開いた状態で「ぁあ」→「Userscripts」をタップし、更新の案内（Updates）が出ていればタップするだけです。
- すぐに確かめたいときは、Userscriptsのメニューの中の更新ボタン（Updates）から手動で確認できます。
- 設定（送り先URLや練習モードなど）は、更新しても消えません。

## あとで見るリスト（使う人だけ）

`gas/` フォルダの `Code.gs` と `Index.html` を、自分のGoogleスプレッドシートのApps Scriptに貼り付けて使います。
`list-template.csv` は見出し行だけのひな形です。
URLや合言葉（API_KEY）はiPhoneの中だけに保存され、このリポジトリには入っていません。
